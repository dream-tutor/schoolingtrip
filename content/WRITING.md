# 글 페이지 원고 규칙 — schoolingtrip.com

스쿨링트립은 방학 해외캠프 6개 과정과 중고등 유학·대학 진학을 안내하는 사이트다. 읽는 사람은 초3~고2 자녀를 둔 학부모다.
같은 운영사 과정을 **러닝트래블(edujourney.co.kr)** 이 이미 안내하고 있어서, 이 사이트의 글은 **사실은 같되 문장·구성·제목이 전부 달라야** 한다.

## 1. 파일 형식

`content/pages-NN-이름.js` 하나가 페이지 객체 배열을 내보낸다. 본보기는 `pages-00-sample.js`. 틀(머리·표·목록·관련 글·상담 버튼)은 `build.js` 가 입힌다 — HTML 을 짜지 말고 아래 칸만 채운다.

```js
module.exports = [
  {
    slug: "ask-first-age",          // PLAN.md 에 정해진 그대로
    group: "ask",                   // ask | camp | pick | study | stpaul | college | path | grade | term
    parent: "camp-malaysia",        // camp 글은 과정 slug / study 글 "study" / stpaul 글 "stpaul" / college 글 "college" / path 글 "pathway" / 그 밖에는 생략
    topic: "처음 정할 때",           // ask 글만. PLAN.md 의 topic 그대로
    title: "…",                     // 32자 이내(뒤에 " | 스쿨링트립" 이 붙어 40자). 검색어가 앞에 오게. ':' 와 줄표(—) 쓰지 않는다
    crumb: "첫 캠프 학년",           // 브레드크럼·용어 목록에 쓰는 짧은 이름(2~12자)
    desc: "…",                      // 40~80자. 아래 3번 규칙
    kicker: "First trip",           // 영문만, 1~3단어
    h1: "첫 해외캠프,<br>몇 학년부터", // 짧게. <br> 한 번까지
    lead: "…",                      // 2~3문장. 이 글의 답을 사실로 먼저 말한다
    art: "malaysia",                // canada | newzealand | japan | malaysia | philippines | seoul | globe — 내용과 맞는 나라, 없으면 globe
    course: "",                     // (선택) 상담 폼에 미리 고를 과정 이름. camp 글은 자동
    sections: [ … ],                // 3~6개. 아래 2번
    camps: ["camp-malaysia"],       // (선택) 과정 카드를 붙인다 — 참가비·기간·마감일이 data.js 에서 자동으로 나온다
    campsTitle: "600만원 아래 과정", // (선택) 그 카드 묶음의 제목
    faq: [["질문", "답"]],           // (선택) 0~4개. 본문에서 이미 답한 것을 되풀이하지 않는다
    related: ["camp-malaysia", "ask-english-level", "camps"], // 2~4개. PLAN.md 의 slug, 과정 slug, 또는 camps·study·stpaul·college·pathway·safety·faq·guide·terms
    cta: ["제목", "한두 문장"],       // (선택) 맨 아래 상담 안내. 페이지마다 그 글의 사실을 근거로 다르게 쓴다
  },
];
```

## 2. 섹션

```js
{ en: "By course",      // 영문 라벨 1~3단어 (영문만)
  h2: "과정마다 받는 학년이 다릅니다",
  p: ["문단", "문단"],                                   // 줄글
  table: { label: "표 이름", head: ["", "A", "B"], rows: [["행 이름", "…", "…"]], narrow: true }, // narrow 는 2칸짜리 좁은 표에만
  pts: [["소제목", "설명"], …],                          // 번호 붙는 항목 2~6개
  duo: [["왼쪽 제목", ["항목", …]], ["오른쪽 제목", ["항목", …]]], // 나란한 상자 2개
  list: ["항목", …],                                    // 상자 안 목록
  steps: [["단계 이름", "설명"], …],                      // 순서 3~6개
  note: [["라벨", "내용"], …],                           // 작은 안내 칸
  after: ["문단"] }                                      // 표·항목 뒤에 붙는 줄글
```
- 한 섹션에 여러 칸을 같이 써도 된다. 그려지는 순서는 p → table → pts → duo → list → steps → note → after.
- **글마다 구성을 다르게.** 모든 글이 `p + pts + p` 로 똑같으면 안 된다. 비교는 표, 순서는 steps, 판단 기준은 pts, 설명은 줄글.
- 글 안에서 쓸 수 있는 태그는 `<a href="파일.html">`, `<strong>`, `<br>` 뿐이다. 링크는 같은 사이트 페이지로만(상대 주소).
- 본문 분량: 일반 글 900자 이상(권장 1,300~2,200자), 용어(term) 450자 이상(권장 600~900자).

## 3. 제목·설명문

- **desc(검색 결과 설명문)**: 검색어를 앞에, 페이지에 있는 사실을 **명사로 끊어 쉼표로** 잇는다. 예) `해외캠프 첫 참가 학년, 과정별 대상 학년표, 초3·초4가 갈 수 있는 과정, 보내기 전 확인할 세 가지, 무료 상담.`
  - 쓰지 않는 꼴: `~합니다/~해 드립니다` 문장, `~을 찾으신다면`, `~부터 ~까지`, `정리했습니다·다룹니다`, `키워드: 문장`, 괄호 속 키워드 나열, `…`. 제목을 그대로 되풀이하지 않는다.
- **title**: 학부모가 검색창에 칠 말로. 32자 이내. 페이지마다 달라야 한다.

## 4. 사실 — 어디서 가져오나

1. **이 사이트 `data.js`** (가장 먼저). 과정 6개의 일정·참가비·대상·정원·포함/불포함·일정표·FAQ, 유학 2개, 세인트폴, 토플면제교육원, 그 밖의 길, 공통 규정(신청 절차·환불·안전·FAQ).
2. **러닝트래블 원자료** `../../러닝트래블(edujourney)/site/` 의 `data.js`·`study-data.js`·`extra-data.js`·`elc-data.js`·`guides*.js` — 같은 운영사 자료라 **사실만** 가져온다. **문장을 옮기지 말 것. 제목·소제목·문단 순서·비유도 따라가지 말 것.**
3. 누구나 아는 일반 사실(뉴질랜드는 남반구라 1월이 여름 같은 것)은 써도 된다. **금액·규정·통계·기관 방침은 위 자료에 있는 것만.** 자료에 없으면 '상담 때 안내합니다'로 두거나 쓰지 않는다. **지어내지 않는다.**

### 토큰 (꼭 쓸 것)
참가비·기간·대상·정원·마감일은 숫자를 직접 적지 말고 토큰으로 쓴다. 시즌이 바뀌면 data.js 만 고친다.
- 과정: `{{camp-malaysia.price}}` `{{camp-newzealand.priceAll}}`(3·4·7주 전부) `.period` `.weeks` `.target` `.targetLong` `.capacity` `.air` `.name` `.short` `.deadlineKo` `.departKo` `.backKo` `.pocket` `.school` `.schoolShort` `.stayShort`
  - 과정 slug: camp-malaysia · camp-philippines · camp-canada-3week · camp-canada-7week · camp-newzealand · camp-japan
- 유학: `{{study-newzealand.price}}` `{{study-canada.price}}` `.unit` `.diploma` `.target`
- 세인트폴: `{{stpaul.price}}` `{{stpaul.intake}}` `{{stpaul.target}}`
- 대학 진학: `{{college.open}}`(개강일) `{{college.seats}}`(모집 인원)
- `{{site.season}}` = "2027 겨울"
- 과정별 금액을 그대로(`599만원` 등) 적으면 검사에서 걸린다. 항공료 예상(250~300만원), 용돈(300~500달러), 신청비 50만원, 선택 프로그램 금액 같은 것은 토큰이 없으니 자료에 있는 숫자를 그대로 적는다.
- "지금 모집 중", "곧 마감" 처럼 날짜가 지나면 틀려지는 말은 쓰지 않는다. 마감일은 토큰으로 날짜만 적는다.
- 한시 할인(10월 등록 할인, EF 장학금)은 글에 쓰지 않는다.

## 5. 쓰면 안 되는 것 (검사에서 걸린다)

- **전화번호 글자** 어떤 번호도. 운영사 내부 명칭(바인그룹·유학사업팀), 수수료 같은 내부 정보.
- **세인트폴 대치 아카데미**: '국제학교' 금지. '미국 교과과정·미국 커리큘럼' 금지 → '8~12학년 과정 · 전 과목 영어 수업'. '미국 졸업장을 받는다' 금지. 비용은 **연간 학비만**(교재비·입학금·관리비 언급 금지). 국내 학력이 인정되지 않는 미인가 대안 교육시설이라는 고지는 관련 글에 꼭 넣는다. 대상은 8~12학년 나이(중2~고3).
- **합격·성적·기간을 약속하는 말**: 합격률, '~개월이면 됩니다', '실력이 오릅니다' 같은 보증. 진학 실적은 '학교 발표 자료 기준'으로 사실만.
- **과장 수식어**: 최고의·완벽한·검증된·놀라운·특별한 경험·잊지 못할·소중한 경험.
- **재촉**: 선착순·마감 임박·서두르세요·지금 바로.
- **자기 해설**: '정리했습니다·다룹니다·살펴보겠습니다·알아봅니다·소개합니다·모았습니다·이 글에서는'. 글이 자기가 하는 일을 설명하지 않는다. 그냥 내용을 말한다.
- **AI 말투**: 수사 의문으로 시작하기('~일까요?'), '결론부터 말하면', '그렇다면', '뿐만 아니라', '무엇보다도', '저절로', 셋씩 나열하는 버릇, 대조 구문 남발('A가 아니라 B입니다'를 한 글에 두 번 넘게), 훈계조 마무리, 느낌표, 줄표(—), 문장 속 이모지, 번역투.
- 상담 안내를 페이지마다 같은 틀('A를 알려 주세요 → B해 드립니다')로 찍지 않는다.
- 일본 과정 용돈은 70~80만원으로 쓴다(자료에 다른 값도 있으나 이 값으로 통일).
- 강의·수업 효과를 설명할 때 근거 없는 수치 금지.

## 6. 말투

- '~습니다' 체. 상담 선생님이 학부모에게 차분히 설명하는 말투. 짧은 문장, 사실과 숫자.
- 첫 문단에서 답을 먼저 말한다. 배경 설명으로 시작하지 않는다.
- 아이가 겪는 장면을 구체적으로 쓴다(예: '저녁 9시가 되면 휴대폰을 호스트 부모님께 맡깁니다').
- 과정 이름은 처음 나올 때 링크를 건다(`<a href="camp-japan.html">교토 일본어 연수</a>`). 관련 글도 본문 안에서 한두 번 링크한다.
- 같은 묶음의 다른 글과 **문단이 겹치지 않게** 쓴다. 겹치는 내용은 그 글로 링크하고 넘어간다.

## 7. 검사

파일을 쓴 뒤 사이트 폴더(`site/`)에서:

```
CHECK_FILE=pages-NN-이름.js node build.js
```
`✓ 원고 검사 통과` 가 나올 때까지 고친다. 이 명령은 그 파일만 읽고 `docs/` 를 건드리지 않는다. **`CHECK_FILE` 없이 `node build.js` 를 돌리지 말 것**(다른 사람이 쓰는 중인 파일과 섞인다). 다른 파일은 고치지 않는다.
